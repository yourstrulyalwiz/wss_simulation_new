---
name: Service-level gap attribution
description: The user's chosen policy for separating shared BAU financing gaps by service level.
---

When separating Safely Managed and Basic financing gaps, attribute replacement using each level's actual costed asset stock, **not** the configured new-investment split. Fund replacement first; only then use the configured split for new-service funding, with unused allocations transferable between levels. Preserve the shared sector-wide gap as the reconciled total.

**Why:** The user explicitly chose this approach after comparing replacement obligations with a blanket percentage split. An investment preference need not match the mix of assets requiring renewal.

**How to apply:** Any future service-level gap displays or exports should explain this accounting distinction and reconcile the attributed figures to the existing sector-wide amount; do not mistake the BAU household-growth replacement stock for the separate target-needs replacement used in the financing-gap total.
